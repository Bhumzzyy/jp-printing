## 📌 1. Project Overview & Mission

**JP Printing & Signs** is a modern, responsive web application for a commercial printing and custom signage company based in Ontario, Canada. Managed by Jot Panag and Deepi Panag, the company provides high-impact commercial print products, custom business signage, marketing collateral, large-format graphics, and promotional items.

### Key Highlights
- **100% Static Pre-rendering (SSG)**: 31 production routes generated at build time with `generateStaticParams`.
- **Hybrid Cloudflare Deployment**: Supports both zero-configuration **Cloudflare Pages** (static export) and **Cloudflare Workers** via **OpenNext** with **Cloudflare R2** persistent incremental caching.
- **Fluid CMYK Responsive Design**: Mobile-first architecture tested and verified across all mobile breakpoints (**320px**, **375px**, **390px**, **430px**, **768px**, **1024px**, and **1440px**).
- **Zero Third-Party CSS Framework Overhead**: Pure Vanilla CSS and scoped CSS Modules with custom CMYK design tokens, avoiding bulky runtime CSS bundles.

## 🧭 4. Application Routes & Architecture

### 1. Home (`/`)
Composed of 9 purpose-built sections in [src/app/page.tsx](file:///D:/client/jp-printing/src/app/page.tsx):
- **Hero** (`HomeHero`): Split layout featuring punchy headline, CMYK ambient gradients, an automated 3-slide visual showcase, and floating preview cards.
- **What We Make** (`jh-products`): 4 quick category cards (Business Cards, Flyers, Stickers, Signs).
- **The Good Stuff** (`FeaturedProducts`): High-converting cards for top-selling commercial prints.
- **Marquee Ticker** (`PrintTicker`): Fast, lightweight infinite CSS marquee.
- **From Paper to Places** (`PrintAndSigns`): High-contrast split banners routing users to either Printing or Signage.
- **The Collection** (`ProductGallery`): Asymmetric responsive CSS grid showcasing 8 distinct print specialties.
- **Signage Banner** (`FeaturedSignage`): High-impact dark parallax section highlighting architectural storefront transformations.
- **Process** (`HowItWorks`): Transparent 3-step ordering process reducing client friction.
- **Meet the Team** (`AboutPreview`): Personal introduction to founders Jot & Deepi Panag.

### 2. About Us (`/about`)
Located in [src/app/about/page.tsx](file:///D:/client/jp-printing/src/app/about/page.tsx):
- Details the founders' story, local Ontario production standards, custom fabrication capabilities, customer-first proofs, and turnaround guarantees.

### 3. Contact & Quote Request (`/contact`)
Located in [src/app/contact/page.tsx](file:///D:/client/jp-printing/src/app/contact/page.tsx):
- Interactive client quote inquiry form with instant product category selection (Business Cards, Storefront Signs, Flyers, Vehicle Graphics, etc.).
- Direct contact details: Phone (`905 919 1181`), email, operating hours, and location.
- Interactive FAQ accordion covering file formats (PDF, AI, EPS), bleed requirements, and turnaround schedules.

### 4. Full Services Catalog (`/services`)
Located in [src/app/services/page.tsx](file:///D:/client/jp-printing/src/app/services/page.tsx):
- Filterable catalog grouping all 24 services under **Printing Essentials**, **Marketing & Promotion**, **Commercial Signs & Displays**, and **Promotional Swag**.

### 5. Service Detail Pages (`/services/[slug]`)
Located in [src/app/services/[slug]/page.tsx](file:///D:/client/jp-printing/src/app/services/%5Bslug%5D/page.tsx):
- Dynamic SSG route that pre-renders 24 individual service landing pages via `generateStaticParams`:
  - `calendars`, `take-out-laminated-menus`, `presentation-folders`, `custom-banners`
  - `event-tickets-bookmarks`, `greeting-invitation-cards`, `lawn-signs-feather-flags`, `window-graphics`
  - `business-cards-stationery`, `flyers-brochures-postcards`, `stickers-labels`, and 13 others.
- Each page automatically includes:
  - Custom dynamic SEO metadata (`title`, `description`).
  - Technical specifications (stocks, coatings, sizes, weather-resistance).
  - Feature checklists and popular commercial use cases.
  - Related product suggestions in the same category.

```css
:root {
  --background: #ffffff;
  --foreground: #171717;
  --muted: #707070;
  --border: #eaeaea;
  --surface: #f7f7f7;

  /* Authentic Print CMYK Palette */
  --cyan: #00b9d6;
  --magenta: #e5007d;
  --yellow: #f5d800;

  --container: 1200px;
  --page-padding: 7%;

```

### Typography Hierarchy
- **Headlines & Big Titles**: `Montserrat` (900 Weight, letter-spacing: `-0.04em` to `-0.07em`) for punchy, bold industrial aesthetics.
- **Body & Controls**: `Poppins` (800 / 700 / 500 Weight) for clean, crisp, legible text across all screen densities.
- **Fluid Sizing**: Implemented via CSS `clamp()` (e.g., `font-size: clamp(34px, 8.5vw, 68px)`), ensuring seamless scaling without awkward breaks.

## 🚀 6. Cloudflare Deployment Workflows

The repository is configured to support **two deployment strategies**:

### Strategy A: Cloudflare Pages (Static Export) — *Recommended for Git CI/CD*
Because all 31 routes are statically rendered, [next.config.ts](file:///D:/client/jp-printing/next.config.ts) is configured with `output: "export"`, generating a self-contained static site in `out/`:

1. Connect repository on **Cloudflare Dashboard** > **Workers & Pages** > **Create** > **Pages**.
2. Build Settings:
   - **Framework preset**: `Next.js (Static HTML Export)` *(or `None`)*
   - **Build command**: `npx next build`
   - **Build output directory**: `out`
   - **Node Version**: `20` or `22` (Environment variable: `NODE_VERSION: 20`)

### Strategy B: Cloudflare Workers with OpenNext — *For Edge Cache & Dynamic R2*
Utilizes `@opennextjs/cloudflare` to run as a serverless Worker with static assets and R2 Incremental Caching:

1. **One-Time R2 Bucket Creation**:
   ```bash
   npx wrangler r2 bucket create web-jp-printing-cache
   ```
2. **Deploy via Wrangler**:
   ```bash
   npm run deploy
   ```
3. Cloudflare bindings declared in [wrangler.jsonc](file:///D:/client/jp-printing/wrangler.jsonc):
   - `NEXT_INC_CACHE_R2_BUCKET`: Persistent R2 bucket for Next.js ISR & fetch cache.
   - `ASSETS`: Static asset delivery directly from edge PoPs (`.open-next/assets`).
   - `WORKER_SELF_REFERENCE`: Loopback service binding for ISR revalidation.
   - `IMAGES`: Native Cloudflare Images optimization.

## 🔒 8. Maintenance & Coding Rules

1. **CSS Modules Preservation**:
   Never add blanket wildcard loaders matching `*.css` in `next.config.ts`. Next.js handles CSS Modules (`*.module.css`) and global CSS automatically.
2. **Logo Constraints**:
   Always keep the header logo constrained via `Navbar.module.css` with explicit `max-width`, `height`, and `object-fit: contain` to prevent layout shift.
3. **Adding New Services**:
   To add a service, append an entry to `services` in [src/data/services.ts](file:///D:/client/jp-printing/src/data/services.ts). The app will automatically generate its dedicated landing page at `/services/[slug]` on the next build.
4. **Clean Commits**:
   Ensure both `main` and `master` branches remain synchronized (`git push origin main && git push origin main:master --force`) to avoid Cloudflare Pages branch mismatch issues.
